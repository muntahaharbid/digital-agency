# Nova Digital — Digital Agency Website

## Project Overview

Nova Digital is a responsive digital agency website built using HTML5, CSS3, JavaScript, and Bootstrap 5. The website presents the agency's services, portfolio examples, and a contact form.

## Features

- Responsive navigation bar.
- Hero section with call-to-action buttons.
- About section introducing the agency.
- Services section with service cards.
- Portfolio section with three illustrative project concepts.
- Contact form with client-side validation.
- Responsive layout for mobile and desktop screens.
- CSS animations and hover effects.

## Technologies Used

- HTML5 — semantic page structure.
- CSS3 — styling, layout, animations, and responsive adjustments.
- JavaScript — contact form validation and interactive feedback.
- Bootstrap 5 — responsive grid, navigation, and utility classes.

## How to Run

1. Download or copy the project files.
2. Keep the folder structure unchanged.
3. Open `index.html` in a web browser.
4. Ensure an internet connection is available for the Bootstrap CDN resources.

## Contact Form Limitations

The contact form validates the user's input in the browser. It does not send emails or store submitted data because no backend or form submission service is configured.

## Portfolio Disclaimer

The portfolio cards are illustrative design concepts created for demonstration purposes; they are not presented as verified client projects.
